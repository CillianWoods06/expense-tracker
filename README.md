# Student Expense Tracker

A simple web app for tracking spending, built with plain HTML, CSS and JavaScript (no frameworks).

## Features
- Add expenses with a description, amount and category
- Running total and number of entries
- Spending totals per category, largest first
- Delete entries
- Input validation with a clear error message
- Data saved in the browser (localStorage), so it's still there after a refresh

## Run it
Open `index.html` in any browser. You can also host it free with GitHub Pages
(Settings → Pages → deploy from the `main` branch).

## Skills shown
HTML forms, CSS layout (flexbox, responsive), JavaScript DOM manipulation, event handling and browser storage.
